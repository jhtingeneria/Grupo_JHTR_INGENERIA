Servicios / Estructura de tanques

Descripción del servicio

Diseñamos, fabricamos y montamos tanques metálicos para almacenamiento industrial, atendiendo requerimientos de volumen, presión y compatibilidad con el fluido a almacenar, bajo normativa técnica internacional.

Aplicaciones típicas

  • Tanques de almacenamiento de agua y combustibles
  • Tanques de proceso para plantas industriales
  • Recipientes a presión (según alcance del proyecto)
  • Mantenimiento e inspección de tanques existentes
Ficha técnica (referencial)
MaterialesAcero al carbono / acero inoxidable, según fluido
Normas de referenciaASME Sección VIII, API 650 / API 653
ProcesoFabricación en taller o en sitio, según logística
Control de calidadEnsayos de hermeticidad y radiografiado según proyecto
AlcanceIngeniería, fabricación, montaje y pruebas

Especificaciones referenciales; capacidades y normativa aplicable se definen según el fluido y volumen requerido. No incluye precios — solicita una cotización.
